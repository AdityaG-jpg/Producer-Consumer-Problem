Buffered vs Non-buffered

How does this work?

The same workload (taken from the Simulator tab) is run with no buffer (zero capacity, direct hand-off), a bounded buffer of N slots and an unbounded buffer. Only the buffer changes, so the table shows what a buffer buys (less waiting, more overlap of producing and consuming) and what it costs (memory).
